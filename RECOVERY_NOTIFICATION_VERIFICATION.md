# Recovery Notification Verification Notes

The Recovery route was reachable from the development preview and rendered its loading shell. Full browser interaction testing was then blocked when the sandbox browser redirected to the application sign-in page. The authenticated recovery notification flow is covered by deterministic regression tests instead.

The automated checks validate actionable craving-alert payloads, safe in-app deep links for the notification actions, sober-day reminder copy and Recovery deep links, service-worker action routing, and visible last-alert status wiring in the Recovery page.
